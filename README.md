# Grupo Culata Jovái Arquitectos - Portfolio Web

Sitio estático (HTML + CSS + JS, sin backend) publicado en Vercel.

## Páginas
- `index.html` — portada con carrusel de fotos y datos de contacto.
- `sobre.html` — texto y foto del estudio.

## Estructura
- `styles.css` — estilos de `sobre.html` (el `index.html` tiene sus estilos dentro del archivo).
- `script.js` — animaciones y encabezado de `sobre.html`.
- `images/` — logo, foto del equipo y las fotos del carrusel.

## Cambiar las fotos del carrusel
Editar la lista dentro de `getCarouselImages()` en `index.html` y poner las fotos en `images/`.

## Ver en local
Abrir `index.html` en el navegador.
